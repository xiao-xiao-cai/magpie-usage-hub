    基本信息

    在要接入的 Windows 设备上生成专用令牌，只把输出的 64 位摘要粘贴到这里。
    在设备上生成令牌与摘要

    在 Windows PowerShell 执行命令。保留此窗口，稍后用其中的令牌配置请求头。

    $bytes = New-Object byte[] 32
$rng = [Security.Cryptography.RandomNumberGenerator]::Create()
try { $rng.GetBytes($bytes) } finally { $rng.Dispose() }
$usageHubToken = [BitConverter]::ToString($bytes).Replace('-', '').ToLowerInvariant()
$sha = [Security.Cryptography.SHA256]::Create()
try { [BitConverter]::ToString($sha.ComputeHash([Text.Encoding]::ASCII.GetBytes($usageHubToken))).Replace('-', '').ToLowerInvariant() } finally { $sha.Dispose() }

    中心 OTLP 接收
    直连填写中心的隧道或局域网 IP。Docker 端口映射可监听 0.0.0.0，同机反向代理可监听回环。
    填写 Windows 可达的 HTTP(S) 基础地址。Magpie 会自动追加 /v1/traces。

    配置 Windows Magpie

    中心接收已就绪。在设备的「设置 → 可观测性」填写下列值并开启 OTLP export。

    Collector
    OTLP
    OTLP endpoint
    OTLP headers
    Authorization=Bearer%20<本机令牌>
    Export metrics
    Off
    Request and response content
    Metadata only
    Trace agent conversations
    按需开启以采集会话用量

    在生成令牌的 PowerShell 窗口执行命令，再粘贴到 OTLP headers。

    "Authorization=Bearer%20$usageHubToken" | Set-Clipboard
