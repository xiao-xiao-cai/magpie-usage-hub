# 分级测试规范

## 默认规则

- 先写出可被反例推翻的预期，再选择足以观察它的最小级别。各级可直接进入。只验证受影响的行为和对应失败条件。
- 只用实际存在的命令、测试数据或运行入口。记录实际结果。缺少运行条件时标出哪项结论待验。
- 测试用合成数据、隔离配置和凭据。真实节点操作必须已有本次授权。

## 工作流

| 根据观察点选级 | 操作 | 停止条件 |
| --- | --- | --- |
| L0 静态检查。文档、Skill 或语义不变的格式修改 | 核对事实、差异和本地链接。改 Skill 时校验元数据和资源，并演练触发、边缘与排除场景。 | 本次文字、结构或路由结论已有证据。 |
| L1 定向验证。单个函数或控件 | 费用映射断言零值、缺失与普通值。按钮样式只查看受影响主题、普通态与键盘焦点。 | 目标输出和改变的边界符合预期。 |
| L2 模块集成。HTTP、文件、计时器或页面数据交互 | 用回环模拟端点、临时目录或可控响应驱动实际模块。 | 输出或持久状态正确，且能在注入的故障后恢复。 |
| L3 隔离宿主验收。真实加载、页面桥、重载、安装或跨网关 | 按[插件接入规范](../magpie-plugin-development/SKILL.md)定位实际入口，选能回答问题的最小拓扑。重载用一套，跨网关入账用源和中心两套。 | 在目标版本及形态观察到所声称的行为和相关失败条件。 |

1. 先找已有定向入口。开发环境采用 Bun 且测试文件存在时，命令形式为 `bun test ./path/to/affected.test.ts`。换成实际路径。判断后端类型时另用已配置的类型检查。
2. 对照本次结论选择场景。下表每行独立选用。

   | 要证明的行为 | 最小环境及故障点 | 结束时检查 |
   | --- | --- | --- |
   | `pollIntervalSec` 输入校验 | L1，向实际解析器传入已约定的合法值、缺失值和无效值。 | 合法值保留秒单位，缺失和无效值各按约定处理。 |
   | 配置页的保存与读回 | L2，模拟写入失败、写成功但读回失败、成功读到不同的值。 | 相符时确认保存。读失败时可重读，值不符时保留草稿并显示差异。两种情况都不自动重写。 |
   | 后台采用新间隔 | 仅改调度器时用 L2 可控计时器。要证明真实 Options 保存会使 Bun 采用新间隔时，使用 L3 单宿主。 | 观察后续轮询由唯一任务按新间隔安排。 |
   | 最近同步状态刷新 | L2，让旧请求在新请求前后分别失败。 | 最新请求仍在等待时保留忙碌状态，已完成时保留最新结果。真正依赖 Web 或桌面桥的结论才进入相应形态的 L3。 |
   | 缺回执时保留进度 | L2，模拟后续子批失败、总数相符但一项重复一项缺失，以及中心已接收但状态未保存就中断。 | 失败后持久游标仍旧，重放后模拟中心中每个预期 `rid` 恰有一条，整页确认后才提交新游标。真实中心入账需双实例 L3。 |
3. 新证据表明共享调用方受影响时，加该调用方的定向用例。模拟与真实宿主行为冲突时，升级到对应 L3 场景。失败先定位并复跑相关用例。
4. 仅当明确要求全量、发布验收约定要求全量，或基础性变更经影响分析仍无法界定范围时，执行全量回归。

## 输出格式

```text
级别及理由 | 版本与形态（若相关） | 实际命令或操作 | 预期与观察结果 | 待验证项
```

## Gotchas

- L3 只表示依赖真实宿主。改单实例锁并不会自动触发双实例或全量回归。
- 中心已收到记录时杀掉测试进程，还要验证重放后的记录数和游标。只看请求成功次数发现不了重复计数。
- 准备提交时复用与候选内容相符的证据。只在暂存片段或环境变化影响结论时补验。
