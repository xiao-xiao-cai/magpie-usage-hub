# 按宿主形态验证接入点

**读取条件**：行为取决于短命 CLI、Web、桌面、服务代理或宿主重载。

| 条件 | 执行与观察 |
| --- | --- |
| `magpie plugin list --json` 显示加载成功 | 只记录 CLI 进程的加载结论。要验证常驻进程，进入实际目标形态再观察入口、页面或后台任务。 |
| Web 静态页要访问后台服务 | 等待 `magpie.ready`，取本次加载得到的 `magpie.service` 并导航到服务页。服务从与声明匹配的回环端口提供相对 API。检查浏览器内代理路径、权限和脱敏结果。 |
| 桌面桥返回空服务地址 | 保留主题、普通 Options 及诊断指引，验证实际桌面嵌入页。不得拼接从 Web 复制来的服务地址。 |
| 需要确定 Options 是否触发重载 | 保存前记录当前宿主和该任务的有效配置，保存后在同一运行形态观察配置通知或新宿主启动。核对接收新配置的任务与后续调度来自同一实例。若确实发生接管，再按后台开发规范检查状态与写入所有权。 |
| 要支持无人打开管理页也能恢复 | 在管理页关闭期间从外部观察新增的已确认进度，再验证冷启动、重载和休眠恢复。`keepAlive` 仅影响 iframe。 |
| 服务提供回填等管理动作 | 后端必须校验管理身份、来源和请求，确认目标与历史边界后再执行。 |
