# 提交混合工作区中的本次修改

**读取条件**：其他任务已有暂存内容，或同一文件包含多个任务的修改。

| 操作前状态 | 选择与验证 |
| --- | --- |
| 他人已暂存，另一个已跟踪路径的整个工作区版本都归本次 | 分别检查该路径的暂存与未暂存差异。先 `git commit --dry-run --only -- <本次路径>`，确认后 `git commit --only -m "<标题>" -- <本次路径>`。该命令提交指定路径的整个工作区版本。 |
| 索引原先为空，同一文件内的两项未暂存修改可分开 | 使用 `git add -p -- <路径>` 选取本次片段。分别用 `git diff --cached -- <路径>` 和 `git diff -- <路径>` 核对已选与保留的片段，再核对索引中的路径后提交。 |
| 同一路径有他人的暂存片段，或无法确定一段改动的归属 | 保持该路径和索引现状，指出具体重叠之处。只处理能独立确定归属的路径。 |

操作后对照原始状态，确认其他工作的路径和片段仍在原位置。未跟踪的新文件必须先审查内容，不能直接套用已跟踪路径的提交命令。
