# 插件定位与功能规格

Magpie Usage Hub 面向同时使用多台 Magpie 的管理员。只在中心 Magpie 安装插件，即可在其 Web 看板查询各实例所选周期内的原生本机用量。各实例继续管理自己的模型调用与原生账本。

**当前阶段** `0.5.0` 候选采用中心只读拉取，默认停用。目标环境为服务器 Docker Magpie 与 Windows 原生 Magpie，兼容性和验证进度以验收记录为准。[开发基线](02-开发基线与兼容性.md) · [第六阶段验收](08-开发阶段与验收计划.md#第六阶段中心只读拉取验收)

## 谁需要部署什么

| 参与方 | 部署和使用方式 | 可以看到什么 |
| --- | --- | --- |
| 中心 Magpie | 在服务器安装插件，设置容器内回环网关，通过已登录的 Magpie Web 管理来源。 | 查看中心本机与已启用来源的分项汇总、周期和查询状态。 |
| 有独立 Magpie 的来源电脑 | 通过原生网关向中心开放受限的 WireGuard 访问，签发专用只读 Key。 | 本机模型照常调用，原生用量仍可在本机核对。 |

## 中心只读拉取

| 功能 | 触发与执行方 | 用户可观察的结果与验收依据 |
| --- | --- | --- |
| 登记或维护来源 | 在中心 Web 的「来源管理」输入名称、网关根地址与专用只读 Key，测试连接后保存。 | 来源按稳定 ID 保存，宿主重载后仍可用。管理员可启停来源或轮换 Key。读回凭据时只显示配置状态。[来源管理](06-配置与诊断页面设计.md#来源管理) |
| 查询所选周期 | 打开看板、切换周期或点击刷新时，由中心 Bun 查询各启用来源的原生网关。 | 今天、近 7 天和近 30 天可选，默认近 7 天。每个来源分别显示原生请求数、输入和输出 Token、缓存读写 Token、已计价估算费用、缺价记录数、周期和查询状态。[统计口径](04-网关接口与用量数据规范.md) |
| 应对单一来源失联 | 中心读取本机成功，远程来源超时。管理员恢复网络后刷新。 | 看板仍显示中心本机汇总，远程来源显示「暂不可用」及受控原因。恢复后读取所选周期内仍可见的原生记录。[故障恢复](05-同步流程与故障恢复设计.md) |
| 启用候选模式 | 管理员保存明确启用的中心拉取 Options。 | 已启用的旧版配置显示升级指引。候选配置与旧状态分目录保存，可按固定版本回退。[升级与回退](07-部署接入与运行维护.md#升级与回退) |

例如中心与 Windows 的日期边界不同，选择「近 7 天」时，各行按所属实例的原生周期统计。使用 `computer=this` 返回的本机 `through` 与 `direct` 分项。看板按实例对账，历史可见范围由源端原生账本保留策略决定。供应商实际账单以其自身计量为准。
