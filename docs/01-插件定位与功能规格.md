# 插件定位与功能规格

Magpie Usage Hub 面向同时使用多台 Magpie 的管理员。来源主动上报本机用量后，管理员可在中心 Web 查所选时段的逐来源用量，直到明细行。各实例继续管理自己的模型调用与原生账本。

**当前阶段** `0.6.0` 主动上报候选默认停用。目标环境为服务器 Docker Magpie 与 Windows 原生 Magpie。[开发基线](02-开发基线与兼容性.md) · [第七阶段验收](08-开发阶段与验收计划.md#第七阶段主动上报与明细验收)

## 谁需要部署什么

| 参与方 | 部署和使用方式 | 可以看到什么 |
| --- | --- | --- |
| 中心 Magpie | 安装插件并启用中心角色。通过 Web 登记来源并查看用量；接收服务接受已登记来源的上报。 | 查中心本机和各来源的分项、趋势、明细及同步覆盖。 |
| 有独立 Magpie 的来源电脑 | 安装同一插件并启用来源角色，以令牌从本机向中心上报。 | 从本机网关读取用量，以后台诊断核对配置采用和上报进度。 |

## 主动上报与明细查询

| 功能 | 触发与执行方 | 用户可观察的结果与验收依据 |
| --- | --- | --- |
| 登记与维护来源 | 管理员在中心 Web 保存来源名称和上报令牌摘要，再把生成的来源 ID 填到来源端。 | 同一来源可以暂停、恢复、轮换或撤销上报令牌。管理页显示认证状态和最近同步。[来源管理](06-配置与诊断页面设计.md#来源管理) |
| 回填与续传 | 来源首次读取原生可见历史，之后按中心检查点同步变更。 | 来源断开时历史仍可查。重连后可读的积压按原调用时间补入对应时段，修订和删除同步到其所属来源。[故障恢复](05-同步流程与故障恢复设计.md) |
| 查询时段及明细 | 在中心看板按时间范围、来源、模型和用量分项筛选。 | 默认近 7 天，另有今天、近 30 天及自定义区间。可查看逐来源总量、小时或日趋势、模型用量和分页明细。[统计口径](04-网关接口与用量数据规范.md#怎样解释中心统计) |
| 校验数据新鲜度 | 打开看板或查看来源详情。 | 查看认证、追赶、暂停、离线、重建和同步缺口状态。覆盖区间取已发布数据的最早及最晚原调用时间。[配置与诊断](06-配置与诊断页面设计.md) |

例如 Windows 离线期间在 9:10 产生用量，10:05 恢复网络后上报，中心在 9 时段计入这条记录。历史回填的范围取决于源端仍可读取的原生记录。若中心与来源的日期边界不同，对账时按来源原生的周期起点和采样截止时间查询。[时间与计量口径](04-网关接口与用量数据规范.md#怎样解释中心统计)
