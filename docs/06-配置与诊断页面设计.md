# 配置与诊断页面设计

管理员在 **Magpie Usage Hub** 的原生插件页保存中心启动设置，再通过同一实例的 Magpie Web 打开用量看板和来源管理。宿主后端通过清单声明的 `3493` 回环页面服务提供页面。桌面配置页在服务入口为空时指引管理员使用 Web。[部署接入](07-部署接入与运行维护.md)

## Options 与宿主校验

| 字段 | 用途与规则 |
| --- | --- |
| `collectionMode` | 保存本阶段的配置时写入 `pull`。遇到仍启用的旧版配置，页面显示迁移指引。 |
| `enabled` | 启用当前中心配置。安装默认停用。 |
| `centerGatewayUrl` | 同一容器或宿主内的原生网关根地址，默认 `http://127.0.0.1:3425`。使用 IPv4 或 IPv6 回环字面量。中心本机随看板查询并自动显示。 |
| `requestTimeoutSec` | 每个原生请求的超时秒数，整数 `1`–`120`，缺省 `30`。 |
| `configRevision` | Options 保存修订，用来核对其他窗口的更新及提交后读回的值。 |

页面等待 Options 桥就绪，读回设置后开放编辑。保存后再次读回核对。若读取失败或内容不同，页面保留草稿并提示重新读取。Options 已保存由桥读回确认，查询生效由打开 Web 后的本机结果确认。[开发基线](02-开发基线与兼容性.md)

在 `v0.1.4799` 的隔离实例中，保存 Options 会停止当前 Bun，访问页面服务代理根路径会唤醒宿主。配置页因此从 `magpie.service` 的根路径进入，片段 `#revision=…&view=dashboard` 带上要核对的 Options 修订。根页等同一修订的宿主状态就绪，再进入 `dashboard/`。[宿主交接](05-同步流程与故障恢复设计.md#来源配置与宿主交接)

## 来源管理

| 管理操作 | 页面表现 |
| --- | --- |
| 新增来源 | 输入显示名称、网关根地址和专用只读 Key，测试连接后保存。支持 HTTP(S) 根地址，地址中的用户信息、查询参数、片段和非根路径会被拒绝。 |
| 测试连接 | 宿主按实际用量路径查询，检查返回结构及 Key 是否只看得到自身用量。成功或失败都显示本次验证结果。 |
| 编辑名称或启停 | 已保存项继续使用同一来源 ID。停用后刷新时显示暂停状态，该来源本轮不发查询。 |
| 轮换 Key 或更改地址 | 输入新 Key，重新测试并保存。更改网关地址必须重新输入 Key。已有 Key 只显示配置状态。 |
| 出现修订冲突 | 重新读取来源列表，核对其他窗口的改动，再提交草稿。 |

来源列表、连接测试和保存通过页面代理访问，宿主校验管理令牌。配置读回携带新修订。修改失败时已有配置保持可用。[管理与查询接口](04-网关接口与用量数据规范.md) · [故障恢复](05-同步流程与故障恢复设计.md)

## 中心 Web 用量看板

进入看板即查询。默认近 7 天，可切换今天、近 7 天或近 30 天，或点击「刷新」重新读取。每一行显示来源名称、原生周期、原生请求数、输入与输出 Token、缓存读写 Token、已计价估算费用、缺价记录数和本次查询状态。有原生周期起点时显示原值及其时区偏移。[统计口径](04-网关接口与用量数据规范.md#怎样解释中心统计)

「暂不可用」只影响对应来源。凭据无效、访问被拒绝、超时、网关不可用以及响应不兼容有各自的提示。修复网络或凭据后刷新即可重新读取。当前结果由最新一次请求更新。[故障处理](05-同步流程与故障恢复设计.md#故障处理)
