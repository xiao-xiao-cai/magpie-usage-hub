# 配置与诊断页面设计

第二阶段使用 Magpie 原生 Options 配置。Bun 日志记录就绪、确认、重试和阻塞，状态文件保存最近确认时间。下文的自定义配置页和运行诊断属于第三阶段。[第二阶段连续同步配置](07-部署接入与运行维护.md#第二阶段连续同步配置)

## Options 与宿主校验

| 配置项 | 用途、取值与校验 | 保存后的处理 |
| --- | --- | --- |
| `enabled`、`mode` | 默认停用。连续同步要求 `enabled: true` 和 `mode: "continuous"`。 | 新宿主按已保存的完整 Options 接管。停用以旧宿主退出为准。 |
| `sourceGatewayUrl` | 必须是本机回环网关地址，例如 `http://127.0.0.1:3425`。以实际监听端口为准。Bun 解析 URL 并限制回环访问。 | 与现有来源及筛选指纹核对，通过后才能使用已保存游标。 |
| `sourceCallerKeyId` | 专用来源模型 Key 的 ID，第二阶段必填。 | 保持该筛选条件，续读与首次读取使用同一 Key ID。 |
| `centralGatewayUrl` | 中心网关根地址，例如 `https://magpie.example.com`。HTTPS 必须验证证书，上报遇到重定向即停止，避免凭据转发。 | 已有进度时更换中心，先确认目标和历史范围。诊断仅显示脱敏目的地。 |
| `centralKeyFile` | 指向本机受保护的上报 Key 文件，Options 保存路径。Bun 校验并读取文件。Windows ACL 仅授权宿主账号及必要管理员。 | 页面提供设置路径的输入，诊断只返回配置状态。不回显文件内容，日志和状态摘要不含完整路径。 |
| `initialMode` | 默认 `now`，只采随后新增的记录。显式选择 `start` 时读取该 Key 的可见历史。 | 首次模式写入状态绑定。后续从持久游标续读。 |
| `pollIntervalSec` | 正常轮询间隔，默认 60 秒。取 5–900 范围内的整数秒。 | 由取得任务所有权的调度器在每轮结束后采用。 |
| `requestTimeoutSec` | 单次 HTTP 请求超时，默认 30 秒。取 1–120 范围内的整数秒。 | 超时进入退避重试。与正常轮询间隔分别配置。 |

## 页面入口与操作

| 运行条件 | 交互约定 | 验证观察点 |
| --- | --- | --- |
| 静态插件页 | 声明 `magpie.page.file`，等 `magpie.ready` 后使用 `magpie.options.get()` 和 `.set()`。静态页 CSP 含 `connect-src 'none'`。 | 初次读取时显示加载态。未配置时提供首次设置。握手或读取失败可重试。 |
| Magpie Web | 声明 `magpie.page.service`，在桥就绪后导航到本次进程提供的 `magpie.service` 服务页，由服务页按其 CSP 调用同源相对 API。 | 观察加载、无确认记录、正常同步、受控失败与恢复。重启后重新取得入口 URL。 |
| Windows 桌面 | 基线桥的 `magpie.service` 为空，静态页仍展示普通 Options 和可用操作，提示管理员到已配置的 Web 管理入口查看完整诊断。 | 实机复验桥接读写及说明可见。需要运行数据的区域注明如何取得。后台调度归宿主管理。 |

提交前保留草稿，写入期间防止重复提交。写成功后重新读取 Options，只有读回值与本次提交相符时才显示“已保存”。写失败保留草稿。读回失败允许重读。值不一致时保留草稿、呈现差异，交给用户决定。较早的异步返回不得覆盖后续编辑、较新的刷新结果或它的加载状态。后台是否已采用新轮询间隔，要从唯一任务的后续调度观测。

## 诊断字段与恢复操作

| 可展示的信息 | 管理员应能作出的判断 |
| --- | --- |
| 安全的来源标签、脱敏目的地、凭据是否已配置 | 当前查看的是哪个来源，接下来要检查哪一端。URL 移除用户信息、查询参数等敏感部分。 |
| 最近尝试时间、最近整页确认时间 | 能分辨后台在尝试、已有进度和从未确认。空页已确认表示进度有效推进。 |
| 已确认条数、其中因重复而跳过的条数、计数所属范围 | `skipped` 属于已确认项。标明是本轮还是累计值，避免把跳过项再加到确认数上。 |
| `has_more`、距最近确认的时长、下次重试时间 | 能判断是否还有分页、同步是否滞后和退避何时结束。避免为显示积压总数频繁扫描账本。 |
| 阶段、HTTP 状态、受控失败类别及下一步操作 | 能区分凭据被拒绝、字段不兼容、游标失效及连接超时。用 `textContent` 展示动态文本。页面及控制台不输出原始异常。 |

重新扫描或切换中心前，显示目标、原来源身份对应的标签、起点及历史范围，要求管理员确认。服务端独立校验管理身份、请求来源、目标和当前状态，交给持锁任务执行，并展示新的运行结果。凭据、账号标识、会话、原始请求与响应均不进入诊断。恢复规则见[同步流程与故障恢复设计](05-同步流程与故障恢复设计.md)。
