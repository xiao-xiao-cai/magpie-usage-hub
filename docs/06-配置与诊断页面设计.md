# 配置与诊断页面设计

管理员在 Docker 中心的 **Magpie Usage Hub** 插件页保存中心设置。登录中心 Magpie Web 后，通过 `3493` 回环页面服务打开后台诊断、用量看板和来源管理。Windows 在原生「设置 → 可观测性」配置发送，生效情况在中心来源管理核对。[部署接入](07-部署接入与运行维护.md)

## Options 与宿主校验

| 字段 | 用途与规则 |
| --- | --- |
| `collectionMode` / `role` | 中心保存时写入 `otlp` 和 `center`。升级时宿主兼容已启用的 `push` 中心设置，沿用其网关、监听、端口和时区。 |
| `enabled` | 页面选项「启用 OTLP 接收与看板」。安装默认停用。 |
| `requestTimeoutSec` | 单次中心本机网关请求超时，单位秒。整数 `1`–`120`，默认 `30`。 |
| `configRevision` | 保存时生成的 UUID，用于核对 Options 读回、宿主读取与后台采用。 |
| `centerGatewayUrl` | 中心本机网关的 HTTP(S) 根地址，默认 `http://127.0.0.1:3425`。使用回环 IP 字面量 `127.0.0.1` 或 `[::1]`。 |
| `ingestHost` / `ingestPort` | OTLP 监听 IP 字面量和 TCP 端口。默认 `127.0.0.1` 和 `3494`。端口范围 `1`–`65535`，须避开 `3493` 和中心本机网关端口。Docker 发布接收端口时绑定宿主的 WireGuard 地址。 |
| `timeZone` | 看板预设、日界和显示使用的 IANA 时区，默认 `Asia/Shanghai`。 |

页面读回 Options 后开放编辑。保存时校验字段，再读回设置和修订。读取或保存异常时保留草稿，发生冲突可载入最新设置后核对草稿。后台诊断显示「宿主读取的修订」和「后台采用的修订」。持锁宿主启动接收服务并采用当前修订后，可进入看板。诊断若显示已读取但未采用，按页面状态核对中心网关归属、监听端口和持久目录。[开发基线](02-开发基线与兼容性.md) · [故障处理](05-同步流程与故障恢复设计.md#故障处理)

配置页从 `magpie.service` 根路径打开诊断，导航片段带上保存的 Options 修订。Magpie `v0.1.4799` 保存 Options 后按需重启 Bun。打开同一实例的后台诊断可启动新宿主，根页等对应修订已采用且就绪后开放看板入口。桌面配置页在服务入口为空时指引使用同一实例的 Web。[宿主交接](05-同步流程与故障恢复设计.md#来源配置与宿主交接) · [原生宿主生命周期](https://github.com/yetone/magpie/blob/v0.1.4799/internal/plugin/host.go#L848-L928) · [页面代理](https://github.com/yetone/magpie/blob/v0.1.4799/internal/gui/pageservice.go#L136-L143)

## 来源管理

| 管理操作 | 页面表现 |
| --- | --- |
| 添加 OTLP 来源 | 输入显示名称和上报令牌的 SHA-256 摘要。中心生成来源 ID，Windows 以认证头中的令牌匹配该来源。 |
| 确认接入 | 在 Windows 保存导出设置并产生新用量。中心首次接受有效用量后从「等待首次上报」转为「已收到用量」，显示「最近接收」。 |
| 修改名称或启停 | 沿用来源 ID。暂停期间保留已接收记录，重新启用后可接收后续事件。 |
| 轮换或撤销令牌 | 登记新摘要，在 Windows 更新原生导出请求头。页面显示「已收到新令牌上报，可撤销原令牌」后，撤销原令牌并提升已验证的新凭据。凭据可逐槽撤销，也可一并撤销。 |
| 查看历史来源 | 看到「历史来源」时可查迁移保留的明细。接入原生导出时登记新的 OTLP 来源。 |
| 确认中心本机重建 | 中心本机等待游标恢复时，核对回环网关后确认重建。重建完成前仍查询已发布的数据。 |
| 出现修订冲突 | 重新读取来源列表，核对其他窗口的改动，再提交草稿。 |

管理页通过 Magpie Web 页面代理访问，宿主校验管理令牌。修改成功后返回新修订和脱敏的凭据槽状态。Windows 原生设置持有上报令牌，中心保存摘要。[管理与查询接口](04-网关接口与用量数据规范.md#看板与管理接口) · [Windows 上报配置](07-部署接入与运行维护.md#windows-上报配置)

## 中心 Web 用量看板

进入看板即查询。默认近 7 天，可选今天、近 30 天或自定义起止。按来源、模型、用量分项与趋势粒度筛选，查看分来源汇总、小时或日趋势、模型用量和分页明细。分项包含「网关」「原生本机会话」「OTLP 会话」。自定义起止时间须带时区偏移或 `Z`，如 `2026-11-27T08:00:00+08:00`。[统计口径](04-网关接口与用量数据规范.md#怎样解释中心统计)

OTLP 阶段为 `waiting`、`receiving` 或 `paused`，分别对应「等待首次上报」「已收到用量」「已暂停」。「最近接收」指最近一次提交有效用量批次的时间。判断特定时段的覆盖，应查看原调用时间和明细。历史来源显示已发布数据。中心本机仍显示回填、追赶、最近同步和重建信息，重建时可继续查已发布的历史。刷新读取最新已提交的数据，分页标记失效时重新查询第一页。[故障处理](05-同步流程与故障恢复设计.md#故障处理)
