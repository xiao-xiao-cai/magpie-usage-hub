# 配置与诊断页面设计

管理员在 **Magpie Usage Hub** 的原生插件页保存中心或来源设置。Magpie Web 通过 `3493` 回环页面服务打开诊断，中心实例还可进入用量看板和来源管理。桌面配置页在服务入口为空时指引管理员使用同一实例的 Web。[部署接入](07-部署接入与运行维护.md)

## Options 与宿主校验

| 角色 | 字段 | 用途与规则 |
| --- | --- | --- |
| 两者 | `collectionMode` / `role` | 保存时写入 `push`，角色为 `center` 或 `sender`。旧启用配置显示迁移指引。 |
| 两者 | `enabled` | 启用所选角色，安装默认停用。 |
| 两者 | `requestTimeoutSec` | 单次网关或上报请求的超时秒数。整数 `1`–`120`，默认 `30`。 |
| 两者 | `configRevision` | Options 保存修订，用于核对提交读回、加载与采用。 |
| 中心 | `centerGatewayUrl` | 中心本机网关根地址，默认 `http://127.0.0.1:3425`。使用回环 IP 字面量 `127.0.0.1` 或 `[::1]`。 |
| 中心 | `ingestHost` / `ingestPort` | 接收监听 IP 字面量和 TCP 端口。默认 `127.0.0.1` 和 `3494`。端口范围 `1`–`65535`，须避开 `3493` 及本机网关端口。 |
| 中心 | `timeZone` | 看板预设、日界和显示使用的 IANA 时区，默认 `Asia/Shanghai`。 |
| 来源 | `sourceGatewayUrl` | 来源本机网关根地址，回环规则和默认值与中心本机网关相同。 |
| 来源 | `centerIngestUrl` | 来源可达的中心接收 HTTP(S) 根地址，例如 `http://192.0.2.2:3494`。使用实际中心地址和端口。URL 用户信息、查询、片段和子路径会被拒绝。 |
| 来源 | `sourceId` / `reportKeyFile` | 中心分配的来源 UUID 及存放上报令牌的本机绝对路径。Windows 使用带驱动器字母的路径。文件格式及权限见[Windows 上报配置](07-部署接入与运行维护.md#windows-上报配置)。 |

页面读回 Options 后开放编辑。保存时校验字段，再读回核对设置及修订，读取或保存异常时保留草稿。后台诊断分别显示已加载修订和已采用修订。中心接收就绪后可进入看板。来源配置被采用后还需等待中心认证、页回执和首次回填完成；诊断显示当前阶段、最近页确认、最近同步完成和重试时间。中心对这台来源的最近联系和历史覆盖可在中心 Web 核对。[开发基线](02-开发基线与兼容性.md)

配置页从 `magpie.service` 的根路径打开诊断，导航片段带上保存的 Options 修订。进入中心看板前，根页等待对应修订已采用且宿主就绪。Magpie `v0.1.4799` 保存 Options 后按需重启 Bun。保存后打开同一实例的后台诊断可启动新宿主，验证修订已采用后可关闭页面。[宿主交接](05-同步流程与故障恢复设计.md#来源配置与宿主交接) · [原生宿主生命周期](https://github.com/yetone/magpie/blob/v0.1.4799/internal/plugin/host.go#L848-L928) · [页面代理](https://github.com/yetone/magpie/blob/v0.1.4799/internal/gui/pageservice.go#L136-L143)

## 来源管理

| 管理操作 | 页面表现 |
| --- | --- |
| 新增来源 | 输入显示名称和本机上报令牌的 SHA-256 摘要。保存后将生成的来源 ID 填入来源端。 |
| 确认接入 | 来源发起首次认证后查看最近联系，首轮回填后检查最近完成同步及用量覆盖。 |
| 修改名称或启停 | 沿用已保存来源 ID。暂停后保留数据和进度，重新启用后从原检查点继续。 |
| 轮换或撤销令牌 | 登记新摘要并在来源保存新文件路径。看到待验证凭据已认证后撤销旧凭据，新凭据成为当前凭据。可以撤销一个或全部凭据。 |
| 确认重建 | 来源等待游标恢复时，管理员核对来源后确认重建。完成前可继续读此来源上个已发布版本。 |
| 出现修订冲突 | 重新读取来源列表，核对其他窗口的改动，再提交草稿。 |

管理页通过 Magpie 的 Web 页面代理访问，宿主校验管理令牌。修改成功后返回新修订和凭据配置状态。源令牌及摘要由各自的受保护存储持有。[管理与查询接口](04-网关接口与用量数据规范.md#看板与管理接口) · [故障恢复](05-同步流程与故障恢复设计.md)

## 中心 Web 用量看板

进入看板即查询。默认近 7 天，可选今天、近 30 天或自定义起止。按来源、模型、用量分项与趋势粒度筛选，查看分来源汇总、小时或日趋势、模型用量和分页明细。自定义起止时间须带时区偏移或 `Z`，如 `2026-11-27T08:00:00+08:00`。[统计口径](04-网关接口与用量数据规范.md#怎样解释中心统计)

汇总显示同步状态、已同步调用范围及最近完成时间。来源离线、追赶或重建时可继续查历史。来源仍在联系中心但一段时间没有提交新页时显示「等待新回执」。首次回填与空查询分别提示。重建发现旧版本记录在当前原生历史不可见时，展示可能缺口。查询刷新读取最新已提交数据。出现过期的明细分页标记时，重新查询第一页。[故障处理](05-同步流程与故障恢复设计.md#故障处理)
