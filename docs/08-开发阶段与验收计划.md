# 开发阶段与验收计划

发送插件目前处于设计阶段。开发顺序先回答“能否进入中心原生账本”，再回答“故障后能否补齐且不重复”，最后验证“管理员如何配置并确认后台在工作”。每次改动只选能证明其预期行为和相关失败条件的检查。

## 里程碑

| 阶段 | 交付内容 | 进入下一阶段的依据 |
| --- | --- | --- |
| 1. 跑通隔离链路 | 在两个独立配置和端口的 Magpie 中打通源端游标读取、字段映射、中心 POST 与只读查询。 | 一条合成用量进入中心 `reported`，一条直接调用归为 `through`。分别核对字段、凭据与查询结果。 |
| 2. 持久进度和恢复 | 实现来源身份、锁、整页确认、原子状态写入、重放及退避。 | 在中断位置读回持久游标，验证恢复后每个预期 `rid` 恰好一条，源端模型路径在中心离线时可用。 |
| 3. 配置与诊断 | 接入 Options、Web 服务页和桌面配置桥，提供受控恢复入口。 | 每种声明支持的形态都有独立记录，能判断配置是否已保存、调度是否已生效、故障如何恢复。 |

## 按改动选择验证级别

| 级别 | 本项目的最小验证示例 | 何时停止 |
| --- | --- | --- |
| L0 静态检查 | 改 README 或字段说明时核对引用、本地链接和与目标版本的一致性。改 Skill 时另验元数据、引用和路由。 | 本次陈述或入口均有对应依据。 |
| L1 定向验证 | 成本映射只测已计价零值、缺失、正常值。按钮样式只看受影响主题、普通态及键盘焦点。 | 确认被改的输出和边界值。 |
| L2 模块集成 | 在回环模拟中心、临时状态目录或可控计时器中验证回执、落盘失败、进程中断和重放。页面读写用可控响应覆盖竞态。 | 输出、持久进度和故障后的恢复结果均符合约定。 |
| L3 隔离宿主验收 | 宿主重载或页面桥用一套实际 Magpie。两端网关入账与权限用隔离源和中心。 | 在目标版本及所声明的形态观察到相关行为和失败条件。 |

各级可直接选择。发现共享调用方受影响，增加该调用方的检查。模拟与宿主表现不一致，升级到相应形态的 L3。全量回归适用于明确要求、发布验收约定或影响分析仍无法划定范围的基础改动。下表按涉及的场景选用。详见[项目分级测试规范](../.agents/skills/magpie-testing/SKILL.md)。

## 关键场景与通过标准

| 要证明什么 | 环境与操作 | 必须观察到什么 |
| --- | --- | --- |
| 两条记账路径与请求隔离 | L3 双实例，分别从源和中心调用。中断上报连接后再恢复。 | 源端继续经本机供应商完成调用，中心分别显示 `through` 和 `reported`。恢复后漏传段补齐，重放没有额外行。 |
| 空页、子批与确认边界 | L2 返回空页、后续子批失败，或预期 A、B 却给两次 A。在中心已接收但本地尚未保存时中断。 | 空页保存下一游标。回执不全或后批失败保持旧游标。重放后每个预期 `rid` 恰有一条，整页确认并成功落盘后才推进。 |
| 状态写入和恢复 | L2 使临时文件刷盘或替换失败。提供未知版本或损坏的状态文件。 | 最近持久化的游标仍可读。保留未知或损坏文件并提示恢复。进程中断与设备物理掉电分别取证。 |
| 用量口径 | L1 查字段，再按需 L3 双实例走普通、流式、失败、取消、带计量的回退及跨日记录。 | 核对 Token、状态、已知零成本与缺价、原调用日期。解释中心按尝试行计数与源端逻辑请求数的差异。 |
| 多来源与权限 | L3 在同一隔离中心接入至少两个来源，试用只读 Key 查询、写入及调用模型，再撤销其中一个上报 Key。 | 两个来源可按 `rid` 追查，重启身份稳定。只读 Key 仅可查询。撤销只影响对应来源。 |
| 配置与状态页 | L2 注入保存失败、读回失败、读回不一致和刷新乱序。声明实际桥接行为时，在目标 Web 或桌面做 L3。 | 草稿可恢复，旧响应不能覆盖最新状态。Web 可从服务页读诊断，桌面服务入口为空时仍可操作普通 Options。 |
| 宿主所有权 | L3 单实例，在旧请求仍在途时重载，另验冷启动、关页和休眠恢复。 | 旧任务退出且迟到结果无法写回，新宿主接管并仅保留一个发送循环。无人值守声明须记录关页后实际恢复用时和登录条件。 |
| 历史缺口 | L2 模拟游标失效。L3 隔离中心恢复旧备份，保留原来源身份，确认范围后重扫。 | 只采新增的来源遵守已确认历史边界。可见记录补齐且历史无重复，已清理而依赖备份的部分单独记录。 |

## 证据记录与当前覆盖

| 对象 | 已有观察 | 仍需取得的证据 |
| --- | --- | --- |
| 本机网关只读 | Magpie `v0.1.4758` 已读取汇总、明细、`cursor=start`、`cursor=now` 和续读。`v0.1.4783` 已核对汇总与游标入口。 | 产品发送端的实际字段兼容、中心写入、跨机权限和双端对账。 |
| Windows 隔离示例 | `v0.1.4783` 安装过两个本地示例。CLI 加载 Bun 并输出标记，Web 注册并返回页面资源。`usage:summary` 返回空账本计数，未声明的 `providers:list` 返回 403。 | 浏览器内页面桥、桌面渲染、产品重启续传、关页和无人值守恢复。 |
