# 开发基线与兼容性

`0.7.0` 候选以 Magpie `v0.1.4799` 的原生 OTLP 导出、中心回环网关和页面服务为核对基线。部署时记录 Windows Magpie 版本、中心 Docker 镜像与 Magpie 版本、中心 Bun 版本和插件归档。[Magpie `v0.1.4799`](https://github.com/yetone/magpie/releases/tag/v0.1.4799) · [原生 OTLP 接入验收](08-开发阶段与验收计划.md#原生-otlp-接入验收)

## 实现应依赖的接口

| 接入点 | 兼容性约定 |
| --- | --- |
| Windows 原生 OTLP | 在可观测性设置填写中心 WireGuard 地址和 `Authorization` 请求头。`v0.1.4799` 将 Trace 以 HTTP JSON 发送到 `/v1/traces`，导出正文选仅元数据，指标关闭，按需启用会话 Trace。Windows 网关使用回环。 |
| Docker 中心 Bun | `exports["./server"]` 指向 `server.ts`，默认导出 `{ id, server }`。`server(input, options)` 异步启动中心接收与本机采集，启动前核对回环网关的 Magpie PID 并取得插件状态锁。中心使用 Bun 的 SQLite 支持。 |
| 配置与页面服务 | `options` 来自中心插件安装项，`input.directory` 用于定位专用状态目录。`magpie.page.file` 提供配置页，经 `magpie.ready` 访问 Options。已登录的 Web 通过 `magpie.service` 使用 `3493` 回环页面服务。 |
| 中心原生网关 | `GET /v1/magpie/usage/requests` 提供 `cursor=start` 及续读、`rows`、`deleted`、`next_cursor` 和 `has_more`。用 `computer=this` 的 `through` 与 `direct` 汇总核对中心本机计量。 |

[Magpie 插件文档](https://usemagpie.ai/docs/plugins) · [原生 Trace 传输](https://github.com/yetone/magpie/blob/v0.1.4799/internal/otlp/otel.go#L327-L383) · [Trace 格式](https://github.com/yetone/magpie/blob/v0.1.4799/internal/otlp/otel_wire.go#L131-L214) · [页面服务](https://github.com/yetone/magpie/blob/v0.1.4799/internal/gui/pageservice.go) · [原生游标接口](https://github.com/yetone/magpie/blob/v0.1.4799/internal/gateway/usage_api.go#L74-L123)

两套 Windows Magpie `v0.1.4799` 隔离实例已验证原生网关尝试和会话生成投递，以及中心重启后的明细读回。实际 Docker 中心与 Windows 经 WireGuard 的接入验收按维护窗口进行。[隔离结果和实机验收项](08-开发阶段与验收计划.md#原生-otlp-接入验收)

## 升级时怎样复核

1. 在两端执行 `magpie --version`，记录中心镜像、Bun 和插件版本。核对目标标签的 Trace 传输、字段白名单、原生游标和页面代理契约。[Magpie 发行记录](https://github.com/yetone/magpie/releases) · [数据契约](04-网关接口与用量数据规范.md)
2. 在 Windows 验证仅元数据的 Trace 经 WireGuard 抵达中心，按来源查到新生成的网关尝试或会话用量。在中心宿主内核对回环游标起读、续读和本机汇总。[部署接入](07-部署接入与运行维护.md)
3. 在实际 Web 验证登录、Options 保存读回、代理访问、管理与查询权限以及宿主交接。临时 `magpie plugin list --json` 的加载结果仅覆盖该 CLI 进程。[配置与诊断](06-配置与诊断页面设计.md)
4. 从 `0.6.0` 切换时核对迁移前备份、已发布的历史明细、中心本机游标和新增 OTLP 来源的接收状态。回退时使用升级前的状态快照。[故障恢复](05-同步流程与故障恢复设计.md) · [部署接入](07-部署接入与运行维护.md)

历史基线按版本查阅。`0.6.0` 的自有上报和 `0.5.0` 的原生汇总核对记录见阶段验收。`0.4.0` 曾在 Windows Magpie `v0.1.4799` 和 Bun `1.4.5` 验证隔离安装与合成上报。[第七阶段验收](08-开发阶段与验收计划.md#第七阶段主动上报与明细验收) · [第六阶段验收](08-开发阶段与验收计划.md#第六阶段中心只读拉取验收) · [`v0.4.0` 开发基线](https://github.com/xiao-xiao-cai/magpie-usage-hub/blob/v0.4.0/docs/02-开发基线与兼容性.md)
